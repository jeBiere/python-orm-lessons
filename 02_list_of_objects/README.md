# 02. Несколько строк — несколько объектов

В первом уроке мы превращали одну строку в один `User`.
Теперь сделаем то же самое для каждой строки из `fetchall()`.
Результат — обычный список, по которому можно пройти циклом.

Запусти `demo.py`. Проследи путь: строки → цикл → список объектов.

Вопрос: какой список получится, если запрос не нашёл ни одной строки?

В `task.py` допиши `get_users_by_name()`. В таблице два пользователя
с именем «Аня», поэтому одного `fetchone()` уже недостаточно.
Функция должна вернуть список объектов, а при отсутствии совпадений — `[]`.

Ожидаемый вывод:

```text
1 Аня
3 Аня
[]
Готово!
```

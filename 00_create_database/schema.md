# Структура library.db

База находится в корне репозитория. Все уроки используют этот файл.

## users — читатели

| Колонка | Тип SQL | Может быть NULL | Ограничения и назначение |
| --- | --- | --- | --- |
| `id` | `INTEGER` | Нет у сохранённой строки | Первичный ключ. При вставке без id SQLite назначает его сама. |
| `name` | `TEXT` | Нет | Имя читателя. Уникальность не требуется. |

## authors — авторы

| Колонка | Тип SQL | Может быть NULL | Ограничения и назначение |
| --- | --- | --- | --- |
| `id` | `INTEGER` | Нет у сохранённой строки | Первичный ключ. При вставке без id SQLite назначает его сама. |
| `name` | `TEXT` | Нет | Имя автора. Уникальность не требуется. |

## books — книги

| Колонка | Тип SQL | Может быть NULL | Ограничения и назначение |
| --- | --- | --- | --- |
| `id` | `INTEGER` | Нет у сохранённой строки | Первичный ключ. При вставке без id SQLite назначает его сама. |
| `title` | `TEXT` | Нет | Название книги. Уникальность не требуется. |
| `pages` | `INTEGER` | Нет | Число страниц, `CHECK (pages >= 0)`. В заданиях 0 страниц означает черновик. |
| `author_id` | `INTEGER` | Да | Внешний ключ на `authors.id`. NULL означает, что автор пока не указан. |

## loans — выдачи книг

Каждая строка хранит одну выдачу книги читателю.

| Колонка | Тип SQL | Может быть NULL | Ограничения и назначение |
| --- | --- | --- | --- |
| `id` | `INTEGER` | Нет у сохранённой строки | Первичный ключ. |
| `user_id` | `INTEGER` | Нет | Внешний ключ на `users.id`. |
| `book_id` | `INTEGER` | Нет | Внешний ключ на `books.id`. |
| `borrowed_at` | `TEXT` | Нет | Дата выдачи. Формат по договорённости: `YYYY-MM-DD`. |
| `returned_at` | `TEXT` | Да | Дата возврата в том же формате. NULL означает, что книга ещё не возвращена. |

Формат дат и порядок дат не проверяются отдельными ограничениями базы.

## Связи

- Один автор может быть указан у нескольких книг. У книги может быть один автор или не быть указанного автора.
- У одного читателя может быть несколько выдач.
- Одна книга может встречаться в нескольких выдачах.

У внешних ключей не задано каскадное удаление. Дополнительных ограничений
на количество одновременных выдач одной книги нет.

Полное SQL-описание таблиц находится в [setup.py](setup.py).

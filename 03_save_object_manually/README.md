# 03. Поменяли объект. А база изменилась?

Наш `User` — обычный объект Python. Если присвоить новое значение `user.name`,
поменяется только объект в памяти программы.
Чтобы сохранить имя в БД, мы сами вызываем функцию с `UPDATE` и `commit()`.

Запусти `demo.py`. Перед сохранением объект и строка в базе содержат
разные имена. После сохранения имена снова совпадают.

Вопрос: откуда `save_user()` знает, какую строку обновлять?

В `task.py` допиши `save_user()`: возьми имя и `id` из переданного объекта,
выполни параметризованный `UPDATE`, затем сохрани изменение.
Создавать новую строку не нужно.

Ожидаемый вывод:

```text
В объекте: Анна
В базе до сохранения: Аня
В базе после сохранения: Анна
Готово!
```

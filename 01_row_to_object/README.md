# 01. А что, если возвращать User?

`fetchone()` возвращает строку в виде кортежа: `(1, "Аня")`.
Мы можем сами превратить её в объект и обращаться к имени через `user.name`.
SQL-запрос остаётся тем же.

Запусти `demo.py`. Сравни `row[1]` и `user.name`.
Потом найди место, где строка превращается в `User`.

Вопрос: что возвращать, если пользователя с таким `id` нет?

В `task.py` допиши `get_user_by_name()`: верни объект `User`, если строка
найдена, и `None`, если её нет. В этой учебной базе имена разные.

После выполнения задания программа выведет:

```text
2 Боря
None
Готово!
```

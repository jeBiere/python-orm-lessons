# От sqlite3 к ORM

Небольшие уроки для ученика, который уже писал SQL и функции для работы с
`sqlite3`. Отправная точка: «А что, если функция возвращает объект `User`?»

Понадобятся базовые знания классов: `__init__`, `self`, экземпляры и атрибуты.
Если они пока непривычны, сначала разберите класс `User` из первого примера.

## Как устроены уроки

В каждой папке три файла:

- `README.md` — одна основная идея, вопрос для обсуждения и задание.
- `demo.py` — готовый пример, который можно запустить и менять.
- `task.py` — заготовка для ученика с пометками `TODO`.

Одна папка — один маленький шаг, а не обязательно целое занятие.
Сначала разберите демонстрацию, затем откройте задание.
Заготовки намеренно останавливаются с `NotImplementedError`, пока ученик
не допишет нужный участок. Вместе с реализацией надо удалить эту строку.
В конце заданий есть небольшие проверки результата; их менять не нужно.

ученик уверенно объясняет происходящее. Дальше двигайтесь в его темпе.

## Запуск

Python 3.10 или новее. Команды выполняются из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python 01_row_to_object/demo.py
python 01_row_to_object/task.py
```

Для другого урока замените имя папки. Первые три урока используют только
стандартную библиотеку Python; SQLAlchemy нужна с четвёртого.

Каждый файл сам создаёт SQLite-базу в памяти. После завершения программы
эта база исчезает. Повторный запуск начинается с тех же исходных данных.
Файлы не зависят от выполнения предыдущих уроков.

С четвёртого урока включён `echo=True`: SQLAlchemy показывает выполняемый
SQL. Найдите знакомые `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
Строки журнала отличаются между версиями; ориентируйтесь на сам запрос.

## Для преподавателя

В примерах намеренно повторяются маленький класс и подготовка БД: каждый
файл можно читать сверху вниз. Основной участок отделён комментарием
`Главное в этом уроке`. Подготовку данных можно сначала просто запустить.

В уроке 04 появляются несколько служебных строк. Объясните их назначение,
а затем сосредоточьтесь на связи таблицы и класса. Типы колонок указаны
явно, чтобы пока не вводить аннотации `Mapped[...]`.

В уроке 03 обычный объект не связан с БД. В уроке 06 изменения отслеживает
открытая `Session`, которая загрузила ORM-объект. Для этих примеров
`commit()` — явный шаг сохранения, как в знакомом `sqlite3`.

После урока 08 можно предложить собрать знакомые операции в маленькую
библиотеку функций, как в предыдущей домашней работе.

Примеры используют API SQLAlchemy 2.0. Справка для преподавателя:
[ORM Quick Start](https://docs.sqlalchemy.org/en/20/orm/quickstart.html) и
[описание моделей с явными типами колонок](https://docs.sqlalchemy.org/en/20/orm/declarative_tables.html#declarative-table-with-mapped-column).

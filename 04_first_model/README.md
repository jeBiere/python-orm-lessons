# 04. Описываем таблицу классом

Раньше мы отдельно писали `CREATE TABLE` и отдельно объявляли класс `User`.
Теперь ORM-модель содержит описание соответствующей таблицы.
По этому описанию SQLAlchemy может создать таблицу.

Новые строки в `demo.py`:

- `Base` — общий базовый класс наших ORM-моделей.
- `__tablename__` — имя таблицы.
- `mapped_column()` — описание колонки: тип и ограничения.
- `create_engine()` — настройка доступа к базе.
- `Base.metadata.create_all(engine)` — создание описанных таблиц.

Запусти пример и найди `CREATE TABLE` в журнале.
SQLAlchemy также даёт модели конструктор: можно написать `User(name="Аня")`
без собственного `__init__`.

Вопрос: выполнился ли `INSERT`, когда мы просто создали объект `User`?

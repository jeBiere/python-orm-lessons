# 06. Меняем имя через ORM

В уроке 03 мы изменяли обычный `User`, а затем сами писали `UPDATE`.
Теперь `Session` отслеживает изменения ORM-объекта, который она загрузила.
Мы меняем атрибут и вызываем `commit()`; SQLAlchemy выполняет `UPDATE`.

Запусти `demo.py`, найди `UPDATE` в журнале и сравни с уроком 03.
Результат сохранения проверяется через новую сессию.

Вопрос: где в нашем Python-коде указано новое имя, а где — нужный `id`?

В `task.py` допиши `rename_user()`:

1. Получи пользователя по `id` через переданную сессию.
2. Если его нет, верни `False`.
3. Измени имя, сохрани изменение и верни `True`.

После журнала SQL появятся строки:

```text
Анна
Готово!
```

# 08. Получаем объекты по условию

`session.get()` ищет по первичному ключу. Для других условий нужен запрос.
В `demo.py` мы получаем всех пользователей с именем «Аня».

Сравни две записи:

```sql
SELECT id, name FROM users WHERE name = 'Аня' ORDER BY id;
```

```python
query = select(User).where(User.name == "Аня").order_by(User.id)
users = session.scalars(query).all()
```

Первая строка Python описывает запрос. Во второй сессия выполняет его;
`scalars()` позволяет получать сами объекты `User`, а `all()` собирает их
в список. `User.name == "Аня"` здесь описывает SQL-условие.

Запусти демонстрацию и сравни с ручным преобразованием строк в уроке 02.

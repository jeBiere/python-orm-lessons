# 07. Удаляем пользователя

После получения объекта можно передать его в `session.delete()`.
Затем `commit()` сохранит удаление: из таблицы исчезнет соответствующая строка.

Запусти `demo.py` и найди `DELETE` в журнале.

Вопрос: что вернёт `session.get(User, 1)` после сохранённого удаления?

В `task.py` допиши `delete_user()`:

1. Получи объект по `id`.
2. Если его нет, верни `False`.
3. Удали его, сохрани изменение и верни `True`.

Проверка отдельно убедится, что второй пользователь остался в базе.
После журнала SQL появятся строки:

```text
None
Боря
Готово!
```

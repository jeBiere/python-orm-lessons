# 05. Сохраняем и получаем объект

В предыдущем уроке объект существовал только в Python.
Теперь добавим строку в таблицу, а затем получим её обратно как `User`.

`Session` организует работу с ORM-объектами и базой.
`with Session(engine)` открывает сессию и закрывает её при выходе из блока.
Сам выход из `with` не вызывает `commit()`.
Для этого примера запомни три операции:

- `session.add(user)` — подготовить новый объект к добавлению в БД.
- `session.commit()` — сохранить изменения; здесь выполняется `INSERT`.
- `session.get(User, id)` — получить объект по первичному ключу или `None`.

Запусти `demo.py`. Обрати внимание: `id` появился после сохранения.
Для проверки мы читаем пользователя через другую сессию.

Вопрос: чем отличаются `User(name="Аня")` и `session.add(user)`?
